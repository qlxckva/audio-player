# Аудиоплеер

## Запуск

Зависимости: `pip install -r requirements.txt`

## Что умеет программа

- просит пользователя ввести логин;
- добавляет аудиофайлы MP3, WAV, OGG, FLAC и M4A;
- воспроизводит, ставит на паузу, останавливает и переключает треки;
- показывает время и позволяет перематывать трек;
- меняет громкость и сортирует треки;
- позволяет назначить треку жанр;
- записывает логин и время входа/выхода в `report.txt` при закрытии.

## ООП и требования задания

- `Entity` абстрактный базовый класс; от него наследуются `Track`, `Genre` и `User`.
- У классов сущностей есть свойства с getter и setter, метод `get_info`, сравнение и специальные методы `__eq__`, `__repr__`, `__str__`.
- `Track` сравнивает треки по пути, а сортирует их по названию.
- В `Genre.default_genres()` создаются 10 объектов жанров; список жанров и список треков хранят объекты в коллекциях.
- `GenreMap` — собственный класс для связи пути файла с жанром. Словарь `dict` не используется.
- В `widgets.py` пользовательские классы кнопок, ползунков, подписей, списка жанров и окна входа дополняют стандартные компоненты Qt.
- Интерфейс собран в горизонтальные и вертикальные layouts, отчёт использует формат времени `%d.%m.%Y %H:%M:%S`.

## Файлы проекта

- `main.py` запуск и окно входа.
- `main_window.py` главное окно и логика плеера.
- `models.py` пользователь, трек, жанр и собственный маппинг.
- `widgets.py` компоненты интерфейса.
- `report.py` запись отчёта.
- `config.py` расширения аудиофайлов и настройки отчёта.
